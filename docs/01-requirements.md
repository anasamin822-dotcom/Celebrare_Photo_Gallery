# Requirements
Source: Celebrare Frontend Intern Pre-Screening PDF. Scope is exactly 7 items, nothing extra.
1 React + Vite + Tailwind only (no UI libraries). 2 Fetch 30 photos from picsum.photos/v2/list?limit=30, spinner, error message. 3 Grid 4/2/1 columns, card = photo + author + heart. 4 Search by author, live, no API call. 5 Favourites with useReducer + localStorage. 6 Custom hook useFetchPhotos returns photos, loading, error. 7 useCallback on search handler, useMemo for filtered list.
Also: functional components only, public GitHub repo, 5-min recording, Google Form.
